Student Management System (C++ OOP)
##Description:

A console-based student management system built in C++ using object-oriented programming (OOP) concepts. This program allows users to manage student records through an interactive menu, including adding students, updating grades, and displaying student information.

##Features

Add a new student with name, ID, and grade

Update the grade of an existing student

Display a single student's information by ID

Display all students in the system

Exit the program

##How to Run

1. Clone the repository to your local machine:

git clone <repository_url>

2. Compile the program using your C++ compiler, for example:

g++ main.cpp -o StudentManagement

3. Run the compiled program:

./StudentManagement

4. Follow the menu prompts to interact with the program.

##Technologies Used

C++ Programming Language

Object-Oriented Programming (Classes, Constructors, Methods)

STL Vector for storing student records

##Notes

This project is designed for beginner-to-intermediate programmers to practice OOP concepts and menu-driven programming in C++.
